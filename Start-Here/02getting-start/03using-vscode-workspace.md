# Using The VSCode Workspace

Tantangan ini akan mengajarkan Anda untuk menggunakan workspace Visual Studio Code.

Anda dapat memulai tantangan ini dengan menggunakan tombol Start di bawah.

Ketika dimulai, Anda kemungkinan akan melihat Terminal, seperti pada level sebelumnya. Namun kali ini, tantangan tidak akan memberikan flag sampai Anda beralih ke VSCode!

Anda dapat menggunakan pemilih workspace pada bilah di bawah Terminal (misalnya tombol yang bertuliskan "Terminal") untuk memilih "Code" dan menampilkan antarmuka Visual Studio Code sebagai pengganti terminal.

Sekali lagi, Anda dapat menggunakannya sebagaimana adanya, atau mengklik tombol "layar penuh" (⛶) untuk memaksimalkan tampilan antarmuka agar terasa lebih lega.

Setelah VSCode dimuat, jalankan terminal (tekan **Control-Shift-Backtick** atau klik tombol **☰** di panel kiri VSCode, lalu pilih menu Terminal, dan klik New Terminal).

Ketika kami mendeteksi bahwa Anda telah menjalankan terminal di dalam VSCode, kami akan memberikan flag-nya kepada Anda!

### CATATAN:

Dojo pwn.college akan mengingat antarmuka workspace terakhir (Terminal, VSCode, dll.) yang Anda gunakan dan akan menjadikannya sebagai default. Jadi, tantangan berikutnya yang Anda jalankan secara otomatis akan membuka VSCode secara default sampai Anda mengalihkannya kembali
