# Restarting Challenges

Hacking adalah olahraga kontak (contact sport).

Akan ada saat-saat di mana upaya Anda untuk meretas suatu level justru menyebabkan kerusakan permanen pada lingkungan workspace.

Ketika hal ini terjadi, jangan panik, Anda cukup memulai ulang (restart) tantangan tersebut!

Level ini akan memandu Anda memahami konsep tersebut.

Pada percobaan pertama, sistem akan meminta kata sandi yang belum Anda ketahui.

Ketika kata sandi yang Anda masukkan salah, sistem akan memberi tahu apa kata sandi yang benar, tetapi kemudian akan menghancurkan tantangan dan berkas flag-nya.

Anda harus memulai ulang tantangan (kembali ke halaman ini dan klik tombol Start di bawah!) untuk mencoba lagi.

Cukup jalankan terminal untuk memulainya.

Semoga berhasil!
