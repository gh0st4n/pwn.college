## Ringkasan

*   **Struktur Direktori:** Data disimpan dalam direktori yang tersusun di dalam direktori lainnya, membentuk pohon (tree) yang dimulai dari direktori **root** yang dilambangkan dengan garis miring (`/`).
*   **Direktori Standar:** Linux menggunakan standar direktori tertentu seperti:
    *   `/bin` atau `/usr/bin`: Tempat penyimpanan program/biner.
    *   `/etc`: Tempat berkas konfigurasi sistem.
    *   `/home`: Tempat penyimpanan data pengguna.
    *   `/tmp`: Tempat berkas sementara.
*   **Navigasi Sistem Berkas:** Pengguna dapat berpindah dan melihat isi direktori menggunakan perintah terminal seperti:
    *   `cd` (Change Directory): Untuk berpindah direktori.
    *   `pwd` (Print Working Directory): Untuk melihat lokasi direktori saat ini.
    *   `ls` (List): Untuk melihat isi direktori.
*   **Konsep Path:** Terdapat dua cara untuk merujuk lokasi berkas:
    *   **Absolute Path:** Jalur lengkap yang diawali dari root `/`.
    *   **Relative Path:** Jalur berdasarkan posisi direktori saat ini.
*   **Simbol Khusus:** Karakter `.` merujuk pada direktori saat ini, sedangkan `..` digunakan untuk naik satu level ke direktori induk.
