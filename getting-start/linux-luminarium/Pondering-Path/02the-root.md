# The Root

Jadi, sistem berkas dimulai dari `/`. Di dalamnya, terdapat berbagai direktori lain, berkas konfigurasi, program, dan yang terpenting, *flag*. Pada level ini, kami telah menambahkan sebuah program tepat di `/`, yang bernama `pwn`, yang akan memberikan *flag* tersebut kepada Anda. Untuk menyelesaikan level ini, Anda hanya perlu menjalankan program tersebut!

Anda dapat menjalankan suatu program dengan menyertakan jalurnya pada baris perintah. Dalam hal ini, Anda memberikan jalur yang tepat, dimulai dari `/`, sehingga jalurnya menjadi `/pwn`. Jenis jalur yang dimulai dari direktori akar (root directory) ini disebut sebagai "jalur absolut" (absolute path).

Mulai tantangannya, buka terminal, jalankan program `pwn` menggunakan *path* absolutnya, lalu dapatkan *flag*-nya! Semoga berhasil!
