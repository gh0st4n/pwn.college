# Program and Absolute Path

Mari kita jelajahi jalur yang sedikit lebih rumit! Kecuali untuk level sebelumnya, tantangan-tantangan di pwn.college berada di dalam direktori `challenge`, dan direktori `challenge` ini sendiri terletak tepat di direktori akar (`/`). Dengan demikian, jalur menuju direktori `challenge` adalah `/challenge`. Nama program tantangan pada level ini adalah `run`, dan program tersebut berada di dalam direktori `/challenge`. Jadi, jalur menuju program tantangan `run` adalah `/challenge/run`.

Tantangan ini kembali mengharuskan Anda untuk menjalankannya dengan memanggil *absolute path* (jalur absolut)-nya. Anda perlu mengeksekusi berkas `run` yang berada di dalam direktori tantangan, yang mana direktori tersebut terletak di dalam direktori `/`. Jika Anda menjalankan tantangan ini dengan benar, Anda akan mendapatkan *flag*-nya. Semoga berhasil!
