# Position Thy Self

Sistem berkas Linux memiliki banyak sekali direktori yang berisi banyak sekali berkas. Anda dapat berpindah-pindah direktori dengan menggunakan perintah `cd` (**c**hange **d**irectory) serta menyertakan jalur (path) sebagai argumennya, seperti berikut:

```
hacker@dojo:~$ cd /some/new/directory
hacker@dojo:/some/new/directory$
```

Hal ini memengaruhi "direktori kerja saat ini" (current working directory) dari proses Anda (dalam kasus ini, shell bash). Setiap proses memiliki direktori tempat ia berada saat itu. Alasan di balik hal ini akan dijelaskan lebih lanjut nanti dalam modul ini.

Sebagai catatan tambahan, sekarang Anda bisa melihat apa arti simbol `~` pada prompt tersebut! Simbol itu menunjukkan lokasi direktori (path) tempat shell Anda berada saat ini.

Tantangan ini mengharuskan Anda untuk menjalankan program `/challenge/run` dari lokasi tertentu (yang akan diberitahukan kepada Anda). Anda perlu berpindah ke direktori tersebut (menggunakan perintah `cd`) sebelum menjalankan kembali program tantangan ini. Semoga berhasil!
