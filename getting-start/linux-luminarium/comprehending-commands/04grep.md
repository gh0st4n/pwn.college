# grepping for a neddle in a haystack

Terkadang, isi file yang Anda lihat dari perintah **cat** terlalu besar. Untungnya, kita memiliki perintah **grep** untuk mencari konten yang kita butuhkan! Kita akan mempelajarinya dalam tantangan ini.

Ada banyak cara untuk menggunakan **grep**, dan kita akan mempelajari salah satunya di sini:

```
hacker@dojo:~$ grep SEARCH_STRING /path/to/file
```

Jika dijalankan seperti ini, **grep** akan mencari baris teks yang berisi **SEARCH_STRING** di dalam file dan mencetaknya ke konsol.

Dalam tantangan ini, saya telah memasukkan seratus ribu baris teks ke dalam file `/challenge/data.txt`. Gunakan **grep** untuk mencari flag-nya!

PETUNJUK: Bendera selalu diawali dengan teks **pwn.college**.
