# more catting practice

Anda dapat menentukan berbagai macam jalur sebagai argumen untuk perintah, dan kita akan berlatih lebih lanjut dengan `cat`. Pada level ini, saya akan meletakkan flag di direktori yang tidak biasa, dan saya tidak akan mengizinkan Anda untuk mengubah direktori dengan `cd`, jadi tidak ada flag `cat` untuk Anda. Anda harus mengambil flag tersebut melalui jalur absolut, di mana pun letaknya.
