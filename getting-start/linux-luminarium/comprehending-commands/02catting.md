# catting absolute path

Pada level sebelumnya, Anda menjalankan `cat flag` untuk membaca flag dari direktori home Anda!

Tentu saja, Anda juga dapat menentukan argumen untuk `cat` menggunakan jalur absolut (*absolute path*):

``
hacker@dojo:~$ cat /path/to/file
Hello Hackers!
``

Pada tantangan ini, saya tidak akan menyalin *flag* ke dalam direktori *home* Anda, tetapi saya akan membuatnya dapat dibaca (*readable*).

Anda dapat membacanya menggunakan *cat* melalui jalur absolutnya: */flag*.

**FAKTA MENARIK**:

*/flag* adalah tempat di mana *flag* selalu tersimpan di pwn.college. Namun tidak seperti pada tantangan ini, Anda biasanya tidak bisa langsung mengakses berkas tersebut secara bebas.
