# Listing Files

Sejauh ini, kami telah memberi tahu Anda file mana yang dapat Anda interaksi. Tetapi direktori dapat berisi banyak file (dan direktori lain) di dalamnya, dan kami tidak akan selalu ada di sini untuk memberi tahu Anda nama-namanya. Anda perlu belajar untuk mencantumkan isinya menggunakan perintah **ls**!

Perintah **ls** akan menampilkan daftar file di semua direktori yang diberikan sebagai argumen, dan di direktori saat ini jika tidak ada argumen yang diberikan. Perhatikan:

```
hacker@dojo:~$ ls /challenge
run
hacker@dojo:~$ ls
Desktop    Downloads  Pictures  Templates
Documents  Music      Public    Videos
hacker@dojo:~$ ls /home/hacker
Desktop    Downloads  Pictures  Templates
Documents  Music      Public    Videos
hacker@dojo:~$
```

Dalam tantangan ini, kami telah memberi nama **/challenge/run** dengan nama acak! Daftarkan file di **/challenge** untuk menemukannya. Kemudian jalankan jalur absolut yang ditemukan untuk mendapatkan flag.
