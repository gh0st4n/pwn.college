# [Linux Luminarium](https://pwn.college/linux-luminarium/)

Selamat datang di Linux Luminarium!

Dojo ini akan mengajarkan Anda secara bertahap tentang cara menggunakan antarmuka baris perintah (command line interface) Linux, sekaligus menanamkan beberapa konsep inti Linux di sepanjang prosesnya.

Ini bukan satu-satunya sumber daya seperti ini di internet, dan kami akan berusaha untuk mencantumkan tautan ke sumber daya lain yang relevan jika diperlukan.

Kami berupaya semaksimal mungkin untuk tidak mewajibkan pengetahuan awal tentang Linux, namun kami berharap Anda telah mempelajari [cara menggunakan infrastruktur dojo itu sendiri](https://pwn.college/welcome).

CATATAN:

Dojo ini merupakan proyek yang masih dalam tahap pengembangan dan merupakan hasil kerja sama komunitas!
Jika Anda tertarik untuk berkontribusi, silakan kunjungi halaman [GitHub kami](https://github.com/pwncollege/challenges/tree/main/challenges/linux-luminarium)!
Jika Anda memiliki pertanyaan, komentar, masukan, dan sebagainya, bergabunglah bersama kami di saluran [Discord](https://discord.com/channels/750635557666816031/1241436610369949758).

CATATAN:

Linux Luminarium bersifat sangat dasar (introductory).
Jika Anda sudah merasa nyaman dan mahir menggunakan Linux, silakan lewati dojo ini (kecuali jika ini ditugaskan sebagai bagian dari suatu kursus/mata kuliah, yang dalam hal ini tentu saja jangan dilewati!).

CATATAN:

Dojo ini TIDAK dirancang untuk menjebak atau menyulitkan!
Terkadang, pembaruan dan tantangan arsitektural pada platform pwn.college itu sendiri dapat menyebabkan beberapa tantangan mengalami kendala.
Jika ada tantangan yang berperilaku aneh, harap beri tahu kami di saluran Discord!
