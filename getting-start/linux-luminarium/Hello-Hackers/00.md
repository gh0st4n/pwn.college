# Hello  Hackers

Modul ini akan mengajarkan Anda dasar-dasar **PALING** fundamental dari berinteraksi dengan baris perintah (command line)!

Baris perintah memungkinkan Anda untuk mengeksekusi berbagai perintah.

Saat Anda menjalankan terminal, sistem akan mengeksekusi sebuah shell baris perintah, yang tampilannya akan terlihat seperti ini:

```
hacker@dojo:~$
```

Tampilan ini disebut sebagai **"prompt"**, yang berfungsi meminta (prompting) Anda untuk memasukkan suatu perintah.

Mari kita bedah apa saja yang ada di sini:

- `hacker` pada prompt merupakan username dari pengguna saat ini. Di dalam lingkungan DOJO pwn.college, username ini adalah `"hacker"`.
- Pada contoh di atas, bagian `dojo` pada prompt adalah hostname (nama mesin) tempat shell tersebut berjalan. (Pengingat ini bisa sangat berguna jika Anda adalah seorang administrator sistem yang menangani banyak mesin setiap harinya).
- Pada contoh di atas, hostname-nya adalah `dojo`, tetapi di pwn.college, nama ini akan disesuaikan berdasarkan nama tantangan yang sedang Anda coba.
- Kita akan membahas arti dari tanda `~` nanti! :-)
- Simbol `$` di akhir prompt menandakan bahwa pengguna `hacker` bukan merupakan pengguna administratif (*root/administrator*).
- Pada modul-modul pwn.college selanjutnya, ketika Anda belajar menggunakan exploit untuk menjadi pengguna administratif, Anda akan melihat prompt menandainya dengan mencetak `#` sebagai pengganti `$`, dan Anda akan tahu bahwa Anda telah berhasil!

Bagaimanapun juga, prompt sudah menunggu perintah dari Anda.

Lanjutkan ke tantangan pertama untuk mempelajari cara mengeksekusi perintah secara nyata!
