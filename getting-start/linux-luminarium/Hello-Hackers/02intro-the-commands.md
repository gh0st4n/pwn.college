# Intro The Commands

Dalam tantangan ini, Anda akan menjalankan perintah pertama Anda! Saat Anda mengetikkan sebuah perintah lalu menekan tombol enter, perintah tersebut akan dijalankan, seperti ini:

```
hacker@dojo:~$ whoami
hacker
hacker@dojo:~$
```

Di sini, pengguna menjalankan perintah `whoami`, yang sekadar menampilkan nama pengguna (`hacker`) ke terminal. Setelah perintah tersebut selesai dijalankan, *shell* akan kembali menampilkan *prompt*, siap untuk menerima perintah berikutnya.

Pada level ini, jalankan perintah `hello` untuk mendapatkan *flag*-nya! Perlu diingat: perintah di Linux bersifat *case-sensitive* (peka terhadap huruf besar/kecil); `hello` berbeda dengan `HELLO`.
