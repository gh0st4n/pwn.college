# Using Terminal

Sepanjang perjalanan Anda di pwn.college, Anda akan melakukan interaksi yang tak terhitung jumlahnya dengan terminal Linux, yang secara populer disebut sebagai "shell".

Jika Anda belum menguasai Seni menggunakan Shell, jangan khawatir, Anda pasti akan menguasainya!

Untuk saat ini, kita hanya akan berfokus untuk menjalankannya. Kami mempermudah peluncuran terminal ini: saat Anda memulai suatu tantangan, kami yang akan menjalankannya untuk Anda!

Cukup klik ▶ Start di bawah ini, dan tantangan ini akan dimulai.

Setelah dimuat, terminal akan muncul secara otomatis tepat di bawah teks ini, dan Anda akan diberikan flag pertama Anda!

### Flag?

Sebagai pengingat, platform ini menggunakan flag untuk melacak kemajuan Anda. Flag adalah token kriptografi yang diberikan kepada Anda ketika Anda berhasil menyelesaikan tantangan.

Setelah Anda melihatnya, salin-tempel flag tersebut ke dalam kotak pengiriman di bawah ini lalu kirimkan! Kemudian, setelah Anda mendapatkan konfirmasi bahwa flag tersebut benar, lanjutkan ke tantangan berikutnya!

### Coba sekarang:

Luncurkan terminal.

Salin flag (memblok/memilih teks menggunakan mouse akan secara otomatis menyalinnya ke papan klip Anda).

Tempelkan ke dalam kotak teks Flag di bawah!

#### CATATAN:

Ingin ruang layar yang lebih luas? Anda dapat mengklik tombol "layar penuh" (⛶) untuk memaksimalkan tampilan antarmuka agar terasa lebih lega.
