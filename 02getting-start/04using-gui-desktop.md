# Using the GUI Desktop

Selanjutnya, kita akan menjelajahi Desktop!

Mulai tantangannya dan gunakan pemilih workspace pada bilah di bawah Visual Studio Code (misalnya tombol yang bertuliskan "Code") untuk memilih "Desktop".

Ini akan menjalankan desktop Linux yang siap untuk Anda gunakan!

Tantangan ini mengharuskan Anda untuk membuka terminal di dalam Desktop tersebut, dan kami akan memberikan flag-nya kepada Anda.
