# Getting Started

### 1. Registrasi Akun
Untuk memulai, pengguna harus melakukan registrasi di situs resmi *pwn.college*. Anda perlu memasukkan nama pengguna publik, email pribadi, dan kata sandi untuk membuat akun baru.

### 2. Alur Belajar & Tantangan (Challenges)
Platform ini menggunakan sistem modul (*dojo*). Setiap modul mencakup:
* **Materi:** Video kuliah dan bacaan untuk memahami konsep dasar.
* **Tantangan:** Praktik langsung untuk menerapkan konsep yang telah dipelajari.
* **Tujuan:** Mendapatkan *flag* (data rahasia) untuk membuktikan tantangan telah diselesaikan.

### 3. Akses Lingkungan Kerja
Pengguna memiliki tiga opsi untuk mengakses lingkungan peretasan:
* **VS Code (Browser):** Akses editor kode langsung di dalam peramban melalui tab *Workspace*).
* **Desktop Virtual:** Menggunakan antarmuka desktop yang berjalan di dalam peramban.
* **SSH:** Akses melalui terminal dengan mengunggah *public key* di menu pengaturan.

### 4. Manajemen Data
* **Persistensi:** Direktori `/home/hacker` bersifat persisten, artinya file yang Anda simpan di lokasi ini akan tetap ada meskipun tantangan di-*restart* atau berpindah modul.
* **Non-Persistensi:** File di luar direktori tersebut akan ter-*reset* setiap kali tantangan dimulai ulang.

### 5. Komunitas & Dukungan
Untuk bantuan lebih lanjut, tersedia beberapa kanal dukungan:
* **YouTube:** Untuk menonton rekaman kuliah dan sesi *office hours*. [Link](https://www.youtube.com/@pwncollege).
* **Twitch:** Untuk siaran langsung dan tanya jawab interaktif. [Link](https://www.twitch.tv/pwncollege/videos).
* **Discord:** Forum diskusi untuk berkomunikasi dengan pengguna lain. [Link](https://discord.gg/pwncollege).
